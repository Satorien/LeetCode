## Step 1. Initial Solution

- いくつかデータ構造が思い浮かんだ
    - HashMapでchild→parent
        - UnionFindで解けそう
        - 取りあえずこれで実装してみる
    - HashMapで隣接ノードを追加してBFS/DFS
- 数え方
    - rootsを保持しておいて減らしていく
    - 根本の数をどう数えるか
- findしたrootが一致する場合を考慮できず無限ループを作ってしまった
- 修正版が以下

```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        parent: Dict[int, int] = defaultdict(lambda: -1)
        union: int = 0

        def find_root(node: int) -> (int, int):
            depth = 0
            while parent[node] != -1:
                node = parent[node]
                depth += 1
            return node, depth

        for i, j in edges:
            root_i, depth_i = find_root(i)
            root_j, depth_j = find_root(j)
            if root_i == root_j:
                continue
            if depth_i >= depth_j:
                parent[root_j] = root_i
            if depth_i < depth_j:
                parent[root_i] = root_j
            union += 1
        return n - union

```

### Complexity Analysis

- 時間計算量：O(e * f(e))
    - 結合数に比例する時間
    - find_rootは結合数と相関する計算量だが、正確な見積もりが難しい
- 空間計算量：O(e)
    - edgesに出てくる以上のノードについては考慮しなくて良い

## Step 2. Alternatives

- DFSで実装

```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        node_to_adjacent: Dict[int, List[int]] = defaultdict(list)
        for i, j in edges:
            node_to_adjacent[i].append(j)
            node_to_adjacent[j].append(i)

        visited_nodes: Set[int] = set()
        def visit(i: int) -> None:
            visited_nodes.add(i)
            for j in node_to_adjacent[i]:
                if j not in visited_nodes:
                    visit(j)
            return
        num_components: int = 0
        for i in range(n):
            if i in visited_nodes:
                continue
            visit(i)
            num_components += 1
        return num_components
```

- inをそれぞれの隣接リストに対して行うのでdefaultdictで良いと思ったが、追加していく時はリストの方が良いという見方もある
    - https://github.com/sakupan102/arai60-practice/pull/22/files#r1590628823
    - 実用的にはどちらの処理の方がメインで行われる、高速化したいかで判断するはず

## Step 3. Final Solution

```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        num_components: int = n
        parent: List[int] = [i for i in range(n)]

        def find_root_and_depth(node: int) -> (int, int):
            depth: int = 0
            while parent[node] != node:
                parent[node] = parent[parent[node]]
                node = parent[node]
                depth += 1
            return node, depth

        for i, j in edges:
            root_i, depth_i = find_root_and_depth(i)
            root_j, depth_j = find_root_and_depth(j)
            if root_i == root_j:
                continue
            if depth_i >= depth_j:
                parent[root_j] = root_i
            if depth_i < depth_j:
                parent[root_i] = root_j
            num_components -= 1
        return num_components
```
