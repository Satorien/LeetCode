## Step 1. Initial Solution

- 一文字置き換えた形の文字列があるかを探す処理を繰り返していって、探すキューがなくなったら終わりにする
    - BFSで実装すれば最短が探せる
- 探索実行前の文字列をキューに格納する
    - 最終的に変形回数を出したいので深さを同じキューに保持
- キューに入った文字列はそれ以上早いタイミングで訪れられないので探すリストから削除する
- 探す処理を関数化する
    - 一文字違いの探し方
        - 探す対象と元の単語のあるインデックス以外の一致
            - 初めはあまり考えずにこれで実装してしまい、とても遅かったので変更
        - 元の単語のある位置が別のアルファベットに置き換わったものを探す
    - あとでキューに入れやすいようにリストで一文字違いたちを返す
        - よく考えるとこんなことをせずにcandidatesに入れて行っても良い
- wordListをそのままfor文で回すと探索に時間がかかりすぎる
    - setに変換して探索するように修正

```python
class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        dict_word: Set[str] = set(wordList)

        def find_adjacent(depth_and_word: Tuple[int, str]) -> List[Tuple[int, str]]:
            depth: int = depth_and_word[0]
            word: str = depth_and_word[1]
            adjacent_words: List[Tuple[int, str]] = []
            for i in range(len(word)):
                for letter in string.ascii_lowercase:
                    target_word = "".join([word[:i], letter, word[i + 1:]])
                    if target_word not in dict_word:
                        continue
                    if target_word == endWord:
                        adjacent_words = [(depth + 1, target_word)]
                        break
                    adjacent_words.append((depth + 1, target_word))
                    dict_word.remove(target_word)
            return adjacent_words
        
        if endWord not in dict_word:
            return 0
        if beginWord in dict_word:
            dict_word.remove(beginWord)
        candidates: List[Tuple[int, str]] = [(1, beginWord)]
        while candidates:
            candidate: Tuple[int, str] = candidates.pop(0)
            new_candidates: List[Tuple[int, str]] = find_adjacent(candidate)
            if new_candidates and new_candidates[0][1] == endWord:
                return new_candidates[0][0]
            candidates += new_candidates
        return 0
```

## Step 3. Final Solution

- 関数化した中でendWordの判定も行うべきかは少し微妙
    - 途中で処理を中断できるので速いが関数の挙動を理解する負荷が上がる
    - 何度も書いているとどの程度なら許容か分からなくなってくるのでまた見直したい

```python
class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        words: Set[str] = set(wordList)
        if endWord not in words:
            return 0
        if beginWord in words:
            words.remove(beginWord)
        
        def update_new_candidates_and_get_end_flag(word: str, new_list: List[str]) -> bool:
            for i in range(len(word)):
                word_split = [word[:i], word[i + 1:]]
                for letter in string.ascii_lowercase:
                    new_word = "".join([word_split[0], letter, word_split[1]])
                    if new_word not in words:
                        continue
                    if new_word == endWord:
                        return [], True
                    words.remove(new_word)
                    new_list.append(new_word)
            return new_list, False

        candidates: List[str] = [beginWord]
        depth: int = 0
        while candidates:
            new_candidates: List[str] = []
            depth += 1
            for candidate in candidates:
                new_candidates, end_flag = \
                update_new_candidates_and_get_end_flag(candidate, new_candidates)
                if end_flag:
                    return depth + 1
            candidates = new_candidates
        return 0
```
