## Step 1. Initial Solution

- 再帰かStack/Queueでループを回すか
- BFSかDFSか、どちらでも良さそう
- 深さの心配がいらず、Listで済むのでStack+DFSで実装

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False
        nodes_and_prefix_sums: List[Tuple[TreeNode, int]] = [(root, root.val)]
        while nodes_and_prefix_sums:
            node, prefix_sum = nodes_and_prefix_sums.pop()
            if node.left is None and node.right is None and prefix_sum == targetSum:
                return True
            if node.left is not None:
                nodes_and_prefix_sums.append((node.left, prefix_sum + node.left.val))
            if node.right is not None:
                nodes_and_prefix_sums.append((node.right, prefix_sum + node.right.val))
        return False
```

### Complexity Analysis

- 時間計算量：O(n)
    - 全てのノードを訪れるのでノード数n分
- 空間計算量：O(n)
    - 最悪の場合でもnに比例する量しかStackされない

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False
        remaining = targetSum - root.val
        if root.left is None and root.right is None:
            return not remaining
        return self.hasPathSum(root.left, remaining) or self.hasPathSum(root.right, remaining)
```

## Step 3. Final Solution

- 減算でStackする実装

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False
        nodes_and_remainings: List[Tuple[TreeNode, int]] = [(root, targetSum)]
        while nodes_and_remainings:
            node, remaining = nodes_and_remainings.pop()
            remaining -= node.val
            if node.left is None and node.right is None and not remaining:
                return True
            if node.left is not None:
                nodes_and_remainings.append((node.left, remaining))
            if node.right is not None:
                nodes_and_remainings.append((node.right, remaining))
        return False
```
