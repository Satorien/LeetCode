## Step 1. Initial Solution

- シンプルに考えると時間の枠のサイズのリストを作って予定管理すれば行ける
    - メモリは制約を元に1,000,000個まで必要だが一旦これで実装
        - 後から調べてみるとPythonのリスト長は特に制限がないので大体これで行ける

```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

BOOKED = 1
FREE = 0

class Solution:
    def canAttendMeetings(self, intervals: List[Interval]) -> bool:
        schedule = [FREE for _ in range(1000000)]

        for interval in intervals:
            for time in range(interval.start, interval.end):
                if schedule[time] == BOOKED:
                    return False
                schedule[time] = BOOKED
        return True
```

### Complexity Analysis

- 時間計算量：O(N*K)
    - K = AVG(Interval.end - Interval.start)
    - 最悪のケースでO(M)（今回は最大時間M=1,000,000）
- 空間計算量：O(M)

## Step 3. Final Solution

- NeetCode側ではList[Interval]が引数なので__lt__が定義されていない
    - heappushで新しく作成

```python
class Solution:
    def canAttendMeetings(self, intervals: List[Interval]) -> bool:
        heap_interval = []
        for interval in intervals:
            heapq.heappush(heap_interval, (interval.start, interval.end))

        previous_end = -1
        while heap_interval:
            start, end = heapq.heappop(heap_interval)
            if previous_end > start:
                return False
            previous_end = end
        return True
```
