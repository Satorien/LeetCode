## Step 1. Initial Solution

- 上手い方法が全然思いつかない
    - 後ろから見た方が良さそうではある
    - 後ろ2つが昇順なら入れ替えるだけ
    - 後ろから見て降順じゃなくなるところで降順じゃない要素を入れ替えて、前の要素から昇順にする
        - 前の要素以降はもともと降順になっているので反転させれば良い
- ここまで分かってからが長かった
    - range関数の扱いがなってなかった
        - 降順にしたい時は第3引数に-1を入れる必要があることを失念していた
        - 頭の中で動かすだけだとこういうミスに気づけない
            - 時間的なコスパを考えると覚えていないことはさっさとデバッグして進めた方が良さそう
    - 負のインデックスでいくつものことを考えるのは認知負荷が高かった
    - 定数サイズのメモリしか使えないという制約を満たすためにswapだけで実現する必要があった

```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        if not nums:
            return

        for i in range(2, len(nums) + 1):
            for j in range(1, i):
                if nums[-i] >= nums[-j]:
                    continue
                nums[-i], nums[-j] = nums[-j], nums[-i]
                for k in range(1, (i + 1) // 2):
                    nums[-k], nums[-i + k] = \
                        nums[-i + k], nums[-k]
                return
        nums.reverse()
```

```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        if not nums:
            return

        for i in range(-2, -len(nums) - 1, -1):
            for j in range(-1, i, -1):
                if nums[i] >= nums[j]:
                    continue
                nums[i], nums[j] = nums[j], nums[i]
                for k in range(-1, i // 2, -1):
                    nums[k], nums[i - k] = \
                        nums[i - k], nums[k]
                return
        nums.reverse()
```

## Step 3. Final Solution

- reversedを使ってみた
- また、in-placeのreverseも自前で実装
    - built-inと被らないように少し変な名前になってしまった
    - 本当ならbuilt-inの.reverse()に引数でstart, endが指定できるのが嬉しい

```python
def reverse_from(nums: list[int], start: int) -> None:
    for i in range((len(nums) - start) // 2):
        left = start + i
        right = len(nums) - 1 - i
        nums[left], nums[right] = nums[right], nums[left]

class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        for i in reversed(range(len(nums) - 1)):
            for j in reversed(range(i, len(nums))):
                if nums[i] >= nums[j]:
                    continue
                nums[i], nums[j] = nums[j], nums[i]
                reverse_from(nums, i + 1)
                return
        nums.reverse()
```
