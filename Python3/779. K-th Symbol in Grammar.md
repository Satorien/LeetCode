## Step 1. Initial Solution

- n行目のk番目の数値だけ分かれば良いので規則性を見つけたい
    - 0
    - 01
    - 0110
    - 01101001
    - …
- 2^(n-1)個の中でk番目
    - 2で割れば変換前の行の位置が分かる
    - 1個前の数値が分かればkを2で割った余りから分かる

```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        if n == 1:
            return 0
        if self.kthGrammar(n - 1, (k-1) // 2 + 1) == 0:
            if k % 2 == 1:
                return 0
            return 1
        if k % 2 == 1:
            return 1
        return 0
```

### Complexity Analysis

- 時間計算量：O(n)
- 空間計算量：O(n)

## Step 3. Final Solution

- 一番しっくり来たもので行く

```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        if n == 1:
            return 0
        
        previous_row_length = 2 ** (n-2)
        if k <= previous_row_length:
            return self.kthGrammar(n-1, k)
        return self.kthGrammar(n-1, k - previous_row_length) ^ 1
```
