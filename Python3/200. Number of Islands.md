## Step 1. Initial Solution

- 周りが見ずに囲まれているような領域の数を求める
- grid内をfor文で探していく
    - [i, j]が1の時どうするか
        - 隣接が1か
- Islandの情報の残し方をどうするか
    - Islandsに座標を入れる
        - 形に制約がないので簡潔に表すのは難しい
- for文で回すときにどうやって新しいIslandと判定するか
    - 訪れた範囲を確かめる方法だけだと訪れていない範囲でつながる可能性がある
        - ここまでで15分程度使ってしまったので一旦ストップ
- 答えを見ると、隣接するIslandを踏破してから次に進むようにしている
    - Queueに次に行く場所を追加していく方法が分かりやすい

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        def visit_adjacent(i: int, j: int) -> None:
            visited.add((i,j))
            to_visit.put((i - 1, j))
            to_visit.put((i + 1, j))
            to_visit.put((i, j - 1))
            to_visit.put((i, j + 1))
        
        def unfound_land(i: int, j: int) -> bool:
            return grid[i][j] == "1" and (i, j) not in visited

        import queue
        
        visited: Set[Tuple[int]] = set()
        to_visit = queue.Queue()
        island_count: int = 0
        for i in range(len(grid)):
            for j in range(len(grid[i])):
                if unfound_land(i, j):
                    island_count += 1
                    to_visit.put((i, j))
                while not to_visit.empty():
                    next_i, next_j = to_visit.get()
                    if not (0 <= next_i < len(grid) and 0 <= next_j < len(grid[i])):
                        continue
                    if unfound_land(next_i, next_j):
                        visit_adjacent(next_i, next_j)
        return island_count
```

### Complexity Analysis

- 時間計算量：O(mn)
    - O(陸の数×4)の計算も加算される
    - 1回のテストケースにつき10^6ステップのオーダー
        - Pythonなら10^8ステップ/s程度なので10msの定数倍ずつかかる
- 空間計算量：O(mn)
    - gridのメモリ＋陸の数×定数倍

## Step 3. Final Solution

- unvisited_landの中に有効範囲の判定も入れるか悩んだが二重for文のところでは不要なので入れないで処理
- if unvisited_landのところはcontinueしてインデント下げた方が見やすいかもしれない

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        visited: Set[Tuple[int]] = set()
        island_count: int = 0
        num_rows = len(grid)
        num_columns = len(grid[0])

        def unvisited_land(i: int, j: int) -> bool:
            return grid[i][j] == '1' and (i, j) not in visited

        def traverse_island_from(start_i: int, start_j: int) -> None:
            to_visit: List[Tuple[int]] = [(start_i, start_j)]
            while to_visit:
                i, j = to_visit.pop()
                if not (0 <= i < num_rows and 0 <= j < num_columns):
                    continue
                if unvisited_land(i, j):
                    visited.add((i, j))
                    to_visit.append((i + 1, j))
                    to_visit.append((i - 1, j))
                    to_visit.append((i, j + 1))
                    to_visit.append((i, j - 1))

        for i in range(num_rows):
            for j in range(num_columns):
                if unvisited_land(i, j):
                    traverse_island_from(i, j)
                    island_count += 1
        return island_count

```
