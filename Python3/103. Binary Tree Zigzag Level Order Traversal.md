## Step 1. Initial Solution

- Listを用意しておいてレベルごとに足しこんでいく
- BFSで
- 二重ループにしてwhileの間は同じ高さの処理
- 前から入れるか後ろから入れるかの管理が必要
    - 最終的に値を答えに入れる時だけ意識するのが楽そう
    - left_to_rightで入れる方向を管理
        - 名前が少し分かりにくい気がする
    - dequeで実装すると最後にリストに戻す必要がある

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        zigzag_level_ordered_values: List[deque[int]] = []
        nodes_to_order: deque[TreeNode] = deque([root])
        left_to_right: bool = True
        while nodes_to_order:
            zigzag_level_ordered_values.append(deque())
            for _ in range(len(nodes_to_order)):
                node = nodes_to_order.popleft()
                if left_to_right:
                    zigzag_level_ordered_values[-1].append(node.val)
                else:
                    zigzag_level_ordered_values[-1].appendleft(node.val)
                if node.left is not None:
                    nodes_to_order.append(node.left)
                if node.right is not None:
                    nodes_to_order.append(node.right)
            zigzag_level_ordered_values[-1] = list(zigzag_level_ordered_values[-1])
            left_to_right = not left_to_right
        return zigzag_level_ordered_values
```

### Complexity Analysis

- 時間計算量：O(n)
- 空間計算量：O(n)

## Step 3. Final Solution

- 個人的にはreverseよりこちらの方がしっくり来た

```python
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        zigzag_lists: List[List[int]] = []
        nodes_to_order: Deque[TreeNode] = deque([root])
        depth: int = 0
        while nodes_to_order:
            traverse: Deque[int] = deque()
            for _ in range(len(nodes_to_order)):
                node = nodes_to_order.popleft()
                if depth % 2 == 0:
                    traverse.append(node.val)
                else:
                    traverse.appendleft(node.val)
                if node.left is not None:
                    nodes_to_order.append(node.left)
                if node.right is not None:
                    nodes_to_order.append(node.right)
            zigzag_lists.append(list(traverse))
            depth += 1
        return zigzag_lists
```
